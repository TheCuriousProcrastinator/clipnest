ClipNest Privacy Policy

Effective date: August 29, 2026

What ClipNest does

ClipNest is a browser extension that lets users save webpage content into destinations they explicitly configure, including Obsidian and Notion.

Data ClipNest accesses

When the user invokes ClipNest, the extension may access the active webpage's title, URL, selected text, visible page content, images, links, and other content necessary to create the requested clip.

ClipNest also stores configuration information needed for the extension to work, including destination preferences, Notion presets, field mappings, and Obsidian vault settings.

During a clipping or image-capture workflow, ClipNest may temporarily store clip drafts, captured images or screenshots, and related state in the browser so the requested action can be completed. This data is not sent to a ClipNest server.

How data is used

Data is used only to provide ClipNest's user-facing clipping functionality. ClipNest does not use browsing data for advertising, profiling, analytics, or unrelated purposes.

Obsidian

Obsidian clips are written directly from Chrome to a vault folder selected by the user using the browser's local File System Access API.

Obsidian vault handles, folder permissions, and related local vault access are stored locally on that computer and are not synchronized by ClipNest between computers.

ClipNest does not send Obsidian clip content to a ClipNest server.

Notion

If the user chooses Notion as a destination, ClipNest uses the user's existing logged-in Notion browser session to communicate with Notion over HTTPS and perform the save requested by the user.

ClipNest does not ask the user to provide a Notion password or session cookie, and it does not export or synchronize the user's Notion login session.

Notion preset configuration, including destination identifiers and field mappings, may be stored using Chrome Sync so that the same presets can be available in other Chrome browsers signed in to the same Google account.

A user must still be logged into Notion separately on each computer before ClipNest can save content to Notion from that computer.

Settings export and import

ClipNest can export portable settings to a JSON file when the user explicitly requests an export.

Exported settings may contain Notion preset configuration and supported extension preferences. They do not contain Notion login sessions, authentication cookies, Obsidian vault handles, or local folder permissions.

Chrome Sync

ClipNest may use Chrome's storage synchronization feature for portable Notion preset configuration. Synchronization is handled by Chrome and the user's Google account.

ClipNest does not use Chrome Sync for Obsidian vault access or for Notion authentication sessions.

Third parties

ClipNest does not sell user data. It does not transfer user data to advertising networks, data brokers, analytics providers, or other unrelated third parties.

Data is transferred to Notion only when necessary to fulfill a user-requested action involving Notion.

Developer access

ClipNest does not operate a backend service that receives users' clipped webpage content.

The developer does not have access to the contents of users' Obsidian vaults or Notion clips through ClipNest.

Data retention

ClipNest does not retain clipped content on developer-controlled servers.

Extension settings remain in the browser, Chrome Sync, or user-created settings backup files until the user changes or removes them.

Content saved to Obsidian or Notion remains under the user's control in those destinations.

Chrome Web Store Limited Use

ClipNest's use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact
