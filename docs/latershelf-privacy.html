LaterShelf Chrome Extension Privacy Policy

Effective date: October 1, 2026

LaterShelf for Chrome saves web pages selected by the user to a Readeck server configured by the user.

Information handled

The extension handles the URL and title of a page when the user explicitly chooses to save it, the Readeck server address and API token supplied by the user, and extension preferences such as Fast Save and appearance.

The extension does not continuously monitor browsing activity.

How information is used

The current page URL and title are used only to create a bookmark on the Readeck server selected by the user. The server address and API token are used only to authenticate requests to that server.

Storage

The server address, API token, and preferences are stored locally using Chrome extension storage. Users can remove the saved Readeck connection from LaterShelf settings. Uninstalling the extension removes its Chrome extension storage.

Data transmission

Bookmark data and authentication information are sent directly from the extension to the Readeck server configured by the user. LaterShelf does not route this information through an analytics, advertising, or data-broker service.

Sharing and sale

LaterShelf does not sell user data and does not use it for advertising, profiling, credit decisions, or purposes unrelated to saving pages to the user's reading library.

Analytics and advertising

The Chrome extension contains no advertising SDK and no analytics SDK.

Chrome Web Store Limited Use

The use of information received through Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

Privacy or support questions can be submitted through the developer's GitHub profile.
